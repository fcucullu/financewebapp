# Personal Finance Tracker

> Full-stack web application for personal finance management. Track income, expenses, and visualize spending patterns.

## Features

- Full CRUD for transactions and categories
- User authentication and authorization
- Reporting dashboards with spending breakdowns
- Category-based filtering and search

## Tech Stack

- Python, Django
- PostgreSQL
- HTML/CSS templates
